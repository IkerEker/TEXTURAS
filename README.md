# TEXTURAS

Biblioteca común de texturas, trazos, manchas, elementos y vídeos para todos los plugins y proyectos.
Todo sale de NEONIZADOR, Analog FX, PAPELATOR, A mano y Trazo, **sin duplicados**: 4.304 archivos de origen
(9,4 GB) se quedaron en 1.235 imágenes y 57 vídeos únicos, que aquí están **limpios, separados y catalogados**.

| Carpeta | Qué hay | Archivos |
|---|---|---:|
| `tileables/` | Fondos que se repiten sin costura: papeles (con su escala real), paredes y suelos, madera y cartón, vidrios y plásticos, pintura, grunge, grafito, líquidos | 415 |
| `trazos/` | Trazos sueltos con transparencia: lápiz, carbón, cera, rotulador, boli, pincel, gouache, óleo, aguada | 289 |
| `manchas/` | Manchas de pincel y de tinta, y el banco de 219 goteos reales | 258 |
| `imperfecciones/` | Café, agua, humedad, grasa, óxido, foxing, quemaduras, grapas, clips, sellos… | 168 |
| `bordes/` | Bordes rasgados, viejos, de cartón, de espiral y esquinas, recortados | 155 |
| `luz_y_elementos/` | Fuego, chispas, humo, fugas de luz, burbujas, espuma, moho (transparencia real + versión para Trama) | 148 |
| `superposiciones/` | Texturas 9:16 a pantalla completa, película con polvo, VHS, fotocopia | 114 |
| `pliegues/` | Hojas dobladas de 1 a 6 veces, arrugadas y muy arrugadas (mapas de sombreado) | 76 |
| `video/` | Transiciones de tinta 4K, texturas animadas de papel, humo, tinta en agua, espuma, spray (con versiones en loop) | 57 |

- **`hojas/`**: hojas de contactos de cada carpeta para ver todo de un vistazo.
- **`CATALOGO.md`** y **`catalogo.json`**: la ficha de cada archivo (qué es, modo de fusión, si es tileable, escala, de dónde sale, en qué plugin se usa; en vídeo: fps reales, duración, si empieza en negro, si cubre y descubre, si hace loop…).
- **`CLAUDE.md`**: la guía para que Claude la use bien en cualquier proyecto.
- **`tools/`**: los scripts que lo generan todo (reproducible).

En Photoshop: los PNG ya traen la transparencia (modo Normal); los `_trama.jpg` son el original sobre negro para modo Trama;
relieves y pliegues van en Superponer o Luz suave (gris 50 % = neutro).

> Contiene packs comerciales de Gumroad (transiciones y texturas animadas): el repositorio debe ser **privado**.
